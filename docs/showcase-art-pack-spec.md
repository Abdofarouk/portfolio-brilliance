# Showcase Art Pack Spec

## Objective
Create a unified deep-tech visual language for the Showcase section that communicates strategy and execution. Every visual is aligned to the card text and avoids generic stock imagery.

## Visual System
- **Style:** technical blueprint diagrams, minimal geometry, no photos.
- **Palette:** ink base + sapphire/cyan accent + cool neutrals.
- **Ratio:** 16:10.
- **Narrative pattern:** strategic intent -> architecture mechanism -> execution signal.

## Content-Alignment Rules for Future Assets
- Keep labels aligned to the exact card terminology.
- Prefer architecture primitives (layers, loops, control paths) over decorative motifs.
- Any new card must include one visible execution signal (e.g., pipeline, KPI loop, release wave, standards stage).
